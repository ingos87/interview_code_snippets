# Bulk Address Validation

## Description
As a mailing customer
I want addresses to be validated according to the Deutsche Post conventions
so that my shipments are processed correctly.

## Acceptance Criteria
- The system provides a suitable interface for processing large bulks of address data.
- Validation rules are applied.
- Unsuccessful validations are returned to the client with an appropriate error message.

## Prerequisites
- Validations rules are object to change every 2-3 years
- Customer data is handled with care according to data protection laws
